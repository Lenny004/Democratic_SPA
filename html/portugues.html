Informações sobre o sistema

— O que é Democratic? —

Democratic é um modelo de software de votação eletrônica adaptável a diferentes contextos: juntas diretivas, eleições escolares, assembleias de associações, enquetes internas e consultas organizacionais. Permite emitir votos a partir de dispositivos conectados a uma rede interna ou controlada pela instituição que administra o processo.

— Para quem é indicado —

O modelo foi projetado para equipes que precisam de um processo de votação configurável sem desenvolver um sistema do zero: administradores definem opções e regras, os participantes votam de forma guiada e os resultados são consolidados automaticamente com relatórios visuais prontos para compartilhar.

— Funções principais —

O sistema permite gerenciar opções de voto, registrar participantes, organizar sedes e mesas de votação, validar a entrada de cada votante, confirmar a seleção antes de registrar o voto e atualizar resultados com gráficos (barras, pizza e linhas) conforme a distribuição de votos por opção, sede ou mesa.

Demonstração

— Fluxo de uso —

Democratic segue um fluxo simples em três passos: o administrador configura o processo (opções, participantes, sedes e mesas), os participantes iniciam sessão e emitem seu voto de forma guiada, e o sistema gera resultados com gráficos atualizados automaticamente.

— Passo 1: Configuração —

O administrador cria o processo de votação, define as opções disponíveis, carrega participantes autorizados e atribui sedes ou mesas conforme a organização (empresa, centro educativo, associação, etc.).

— Passo 2: Votação —

Cada participante acessa com suas credenciais, seleciona uma opção e confirma seu voto. O sistema valida a identidade, evita votos duplicados e registra a escolha com segurança.

— Passo 3: Resultados —

Ao encerrar ou durante o processo, os resultados são exibidos em gráficos de barras, pizza e linhas. Consulte a seção Resultados para ver os gráficos de demonstração.

Perguntas frequentes

O que devo fazer se a instalação não iniciar?

É provável que tenhamos desativado o programa porque estamos fazendo manutenção ou pode ser um problema de conexão.

O que devo fazer se o sistema não iniciar após a instalação?

Verifique se o seu sistema operacional é compatível com os requisitos que o programa pede. Se não for o sistema operacional do seu dispositivo, pode ser um erro nos frameworks instalados, atualize-os para a versão necessária. Se não houver nenhum, entre em contato conosco!

O que devo fazer se não conseguir lembrar a senha?

Não se preocupe, o sistema pode enviar a você uma nova senha para o e-mail vinculado e se no caso de você perder o e-mail, entre em contato conosco e estabeleceremos para onde enviaremos uma senha de verificação para um novo e-mail.
